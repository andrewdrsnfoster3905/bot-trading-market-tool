## Overview

bot-trading provides a web-based way to examine stock-market information, with particular attention to IDX-focused analysis. Its lightweight presentation is intended for people who want to review trading data without setting up a large or complicated application.

The tool is organized around market-analysis tasks and can support researchers, traders, and other users comparing stock activity over time. Because it is delivered through the web, it is suited to situations where direct access to analysis data is more important than an elaborate interface.

   - `git clone https://github.com/andrewdrsnfoster3905/bot-trading-market-tool.git
   - or download the latest build from the project page
2. Open the primary HTML entry file in your browser.
3. For a local installation, serve the project directory with a basic web server before opening the application.

For example, start a local server with:

- `python -m http.server`
